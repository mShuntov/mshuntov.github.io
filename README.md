# mshuntov.github.io

Personal site of Marko Shuntov — postdoctoral researcher at the Cosmic Dawn Center (DAWN), Niels Bohr Institute.

Static HTML — no build step. Served by GitHub Pages from the `main` branch.

- `index.html` — main site
- `galaxy-halo.html` — interactive scroll-driven essay on the galaxy–halo connection
- `hod-sandbox.html` — interactive HOD sandbox
- `images/` — favicons
- `.nojekyll` — disables GitHub Pages' Jekyll processing
